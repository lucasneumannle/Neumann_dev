# Acqua Life — landing page

Arquivos estáticos prontos para subir em um repositório GitHub. Publique o conteúdo desta pasta na raiz do repositório e ative GitHub Pages (branch principal, pasta raiz). A página inicial é `index.html`. Não há instalação, build ou dependências.

## Configuração

Edite `config.js` para informar a URL pública em `canonicalUrl`, e, se desejar, os IDs reais de Meta Pixel e Google Analytics. Sem IDs, nenhum script de marketing é carregado. Se um ID for configurado, o site pede consentimento antes de carregar os scripts.

Os serviços listados na página também são editados em `config.js`. O WhatsApp está configurado para **+55 47 99720-7567**. Os botões abrem com mensagem pré-preenchida e registram `whatsapp_click` no `dataLayer`; com consentimento e Pixel ativo, registram também `Lead`.

## Fotos e avaliações

`assets/logo.webp` deriva do logo enviado. `hero.webp` e `evening.webp` são imagens ilustrativas geradas para a interface; **não retratam projetos da Acqua Life**. O link “Ver projetos no Instagram” aponta ao perfil oficial. Quando a empresa disponibilizar fotos autorizadas das próprias instalações, substitua as imagens mantendo os mesmos nomes e proporções.

Os depoimentos são trechos de avaliações públicas atribuídas aos respectivos autores, consultadas em [Achei Perto](https://acheiperto.com/limpadores-de-piscina/joinville/acqua-life-piscinas-e-acessorios/). Confira periodicamente os links e os dados comerciais. A nota numérica do Google foi omitida porque é variável.

As duas imagens ilustrativas foram criadas com a ferramenta integrada ImageGen. Prompts finais: (1) fotografia arquitetônica panorâmica de residência brasileira contemporânea, piscina retangular, pedra natural, luz de fim de tarde, área livre à esquerda para texto; (2) fotografia arquitetônica de piscina residencial ao anoitecer, iluminação interna quente e reflexos suaves. Ambas sem pessoas, texto, logo ou marca.
