# Reset 26 Barbearia

Landing page estática, pronta para subir no GitHub. Não requer instalação, npm ou etapa de build.

## Arquivos

- index.html: página e catálogo completo de 19 serviços, incluindo visagismo.
- style.css: apresentação responsiva.
- app.js: filtros do catálogo.
- assets/: logo enviada e imagem de visagismo da página original.

## Uso

Abra index.html no navegador para visualizar. Envie o conteúdo desta pasta para a raiz do seu repositório, preservando a pasta assets. Se usar uma hospedagem estática, selecione a pasta que contém index.html como diretório da página.
