# CONSTRULEV — landing page de prévia comercial

Página estática, responsiva e pronta para enviar a um repositório GitHub. Não precisa de build, npm ou backend.

## Como visualizar

Abra `index.html` no navegador ou use um servidor estático local para testar exatamente como ficará na hospedagem. Publique todo o conteúdo desta pasta, mantendo `assets/`, `styles.css` e `script.js` ao lado de `index.html`.

## Estrutura

- `index.html`: conteúdo, SEO, links e dados estruturados.
- `styles.css`: layout e adaptação responsiva.
- `script.js`: menu móvel, movimento discreto e eventos de clique.
- `assets/images/*.webp`: imagens arquitetônicas conceituais da prévia.
- `assets/images/construlev-original.jpg`: logo original fornecido para futura referência.
- `design.md`: decisões de direção de arte e sistema visual.

## Antes de publicar para o público

1. Trocar imagens conceituais por fotografias autorizadas da CONSTRULEV, se houver. Enquanto forem usadas as imagens atuais, manter os avisos de que são apenas referências visuais.
2. Confirmar nota, quantidade de resenhas e textos das avaliações no Google. Estes dados vieram do briefing, não foram auditados em fonte pública durante a montagem.
3. Confirmar o endereço completo antes de acrescentar número ou marcador exato ao mapa. A página usa apenas Calle 24, Villavicencio, Meta.
4. Caso use domínio próprio, configurar URL absoluta de `og:image` e, se desejado, `canonical` no `<head>`.
5. Para ligar GA4 ou Meta Pixel, usar os eventos de `dataLayer` já preparados no `script.js`.

## Créditos e limites

As quatro imagens arquitetônicas foram geradas para esta prévia comercial e não retratam trabalhos executados pela empresa. O Instagram informado no briefing não forneceu fotos acessíveis durante a produção. O arquivo de logo original foi enviado pelo solicitante.
