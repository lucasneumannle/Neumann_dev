# ASF Limpeza e Manutenção de Piscinas — prévia

Landing page estática pronta para hospedagem.

## Como visualizar

Abra `index.html` no navegador. Não é necessário instalar dependências nem executar build.

## Como publicar no GitHub Pages

1. Extraia o ZIP.
2. Envie o conteúdo da pasta para a raiz do repositório.
3. No GitHub, acesse **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione a branch e a pasta `/ (root)`.
5. Para domínio próprio, configure o domínio em **Custom domain** e ajuste os registros DNS no provedor.

## Arquivos

- `index.html` — estrutura e conteúdo.
- `styles.css` — design responsivo e acessível.
- `script.js` — microinterações leves.
- `assets/piscina-cristalina.webp` — imagem atmosférica gerada para a prévia; não representa trabalho realizado pela ASF.
- `assets/favicon.svg` — ícone leve com o monograma da prévia.
- `design.md` — decisões visuais, conteúdo verificado e notas de QA.

## Antes de publicar definitivamente

Confirme com a empresa a redação final, a área exata de atendimento, o horário “24 horas” e a autorização de uso de marca/fotos. Trocar a imagem atmosférica por fotografias reais da ASF tende a aumentar a confiança e a conversão.
