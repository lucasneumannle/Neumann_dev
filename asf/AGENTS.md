# LP DESIGN SYSTEM V2

Ao evoluir esta landing page:

1. Preserve fatos verificáveis e atualize `design.md` junto com mudanças visuais duráveis.
2. Não invente serviços, resultados, equipe, urgência, avaliações ou imagens de trabalhos realizados.
3. Mantenha um único CTA dominante: orçamento pelo WhatsApp.
4. Prefira HTML, CSS e JavaScript nativos. Todo movimento deve respeitar `prefers-reduced-motion`.
5. Revise a página renderizada em desktop, tablet e mobile antes de entregar alterações.
