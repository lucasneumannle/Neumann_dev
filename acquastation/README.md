# AcquaStation Piscinas — landing page de prévia

Landing page estática, responsiva e pronta para publicação no GitHub Pages. Não exige build, servidor ou dependências JavaScript.

## Publicação

1. Envie todo o conteúdo desta pasta para um repositório do GitHub.
2. Em **Settings → Pages**, selecione a branch principal e a pasta raiz.
3. Aguarde a URL pública gerada pelo GitHub Pages.

Para testar localmente, abra `index.html` no navegador. Para testar navegação e métricas com maior fidelidade, use um servidor estático local.
