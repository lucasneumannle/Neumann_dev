# Marazul Piscinas — site institucional

Site estático, responsivo e pronto para publicação no GitHub Pages ou em qualquer hospedagem de arquivos estáticos.

## Publicar no GitHub Pages

1. Extraia o ZIP e envie todos os arquivos para a raiz de um repositório.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.

O site não exige instalação, build ou variáveis de ambiente. Abra `index.html` para uma visualização rápida local.

## Personalização

- Telefone e mensagens do WhatsApp estão em `index.html`.
- Textos e seções estão em `index.html`.
- Cores, tipografia e responsividade estão em `styles.css`.
- Interações leves estão em `script.js`.
- Imagens ficam em `assets/images/`.

## Observação sobre imagens

As fotografias de banco são apresentadas como referências de atmosfera e não como obras executadas pela Marazul. Substitua-as por fotografias reais de projetos quando disponíveis, mantendo os mesmos nomes de arquivo ou atualizando os caminhos em `index.html`.
