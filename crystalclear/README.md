# Crystal Clear — landing page

Site estático pronto para publicar no GitHub Pages, Netlify, Vercel ou em hospedagem convencional.

## Como usar

Abra `index.html` diretamente ou rode um servidor local simples. Não há build, dependências ou variáveis de ambiente.

## Estrutura

- `index.html`: conteúdo, SEO e dados estruturados.
- `assets/css/styles.css`: sistema visual e responsividade.
- `assets/js/main.js`: menu, navegação, serviços e animações leves.
- `assets/images/`: logo fornecido pelo cliente e imagens otimizadas em WebP.
