# LP DESIGN SYSTEM V2

Ao editar esta landing page:

1. Mantenha `design.md` e a implementação sincronizados.
2. Preserve fatos verificáveis. Não invente prova, equipe, obras, resultados, depoimentos ou escassez.
3. Mantenha um CTA dominante para WhatsApp e a linguagem visual de refração da água.
4. Prefira CSS e JavaScript nativos. Todo motion precisa de fallback em `prefers-reduced-motion`.
5. Após mudanças visuais, revise a página renderizada em desktop, tablet e mobile.
6. Fotografias de banco são somente ambientação; nunca rotule como trabalho da Crystal Clear.
